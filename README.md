14-year-old software developer from Costa Rica, focused on **autonomous AI architectures, real-time systems, and interactive agents**.

While most AI wrappers just send text to an API and return a response, my goal is to build stateful systems that persist over time, manage internal emotional states, interact with live environments, and learn from their own history.

---

### 🧠 Flagship Project: **Emilia**
Inspired by the technical depth behind *Neuro-sama*, **Emilia** is a local, modular AI entity built in Python (40+ interconnected modules) designed to operate as an autonomous presence rather than a stateless chatbot.

**Core Architecture & Engineering:**
* **Concurrent State & Emotion Engine:** Thread-safe emotional simulation (`threading.RLock`) with inertia, cross-emotion contagion, energy decay, and narrative context shifts.
* **Real-Time Game Integration:** Asynchronous WebSocket server (`asyncio`) implementing the Neuro SDK protocol to connect with a BepInEx mod in *Hollow Knight*, allowing the AI to evaluate combat tactics, navigate rooms, and narrate live gameplay.
* **Long-Term Memory & Dataset Pipeline:** Vector memory retrieval (ChromaDB) paired with an automated data curation, PII redaction, and deduplication pipeline to prepare multi-turn datasets for local LLM fine-tuning (Llama 3 / Phi-3).
* **Autonomous Publishing:** Automated bridge (`emilia-blog`) that sanitizes daily session logs and publishes entries directly via the GitHub REST API.
